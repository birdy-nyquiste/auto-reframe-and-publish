# 任务头只本地化作者和洗稿指令

任务头以 `#投稿` 开始。Blog 的必填 `author.name` 在微信入口中只写作中文字段 `作者`；本地编辑控制只写作中文字段 `洗稿指令`。除这两个字段外，允许投稿者指定的 Blog 字段必须保持接口原名，例如 `author.slug`、`postType`、`category`、`tags` 和 `featured`。

所有字段统一接受半角冒号 `:` 或全角冒号 `：`。冒号只是分隔符兼容，不改变字段名；因此 `author.name`、`文章数`、旧 `目标`/`要求` 以及任何未登记字段都被拒绝。一个任务头仍只关联紧随其后的一篇文章，不再需要用 `文章数` 重复声明。

解析后仍在可信任务记录中保存标准 Blog 对象 `{ "author": { "name": "..." } }`。这项入口本地化不改变 Blog 请求、作者同名匹配规则、发布授权边界或历史任务 Schema。
